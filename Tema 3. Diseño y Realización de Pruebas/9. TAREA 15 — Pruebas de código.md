# TAREA 15 — Pruebas de código

**Distribución de la puntuación**: Práctica con el ordenador **7 puntos (70%)** · Teoría **3 puntos (30%)**

**Material necesario**: el proyecto `pruebas-tema3` en Visual Studio Code con las clases `CuentaBancaria` (ya
corregida en la Tarea 14) y `Entrada` (sin corregir todavía), JDK 17 y Maven.

**Entrega**: un documento con tus respuestas, capturas de pantalla de cada paso, el código de las clases creadas y las
tablas de resultados.

## PARTE PRÁCTICA (7 puntos)

1. **Clases de equivalencia y valores límite.** Para `Entrada.categoria(int edad)` (especificación en la Tarea 14):
   - Escribe la **tabla de clases de equivalencia** (válidas y no válidas) con un representante de cada una.
   - Escribe la **lista de valores límite** de cada frontera.
   - Crea la clase `PruebaLimites` con un `main` que ejecute **todos esos casos** e imprima `OK` o `FALLO`.
   - Ejecútala sobre la versión **sin corregir** de `Entrada`, identifica el defecto, corrígelo y vuelve a ejecutar.

   Entrega las dos tablas, el código, la salida antes y después de corregir y la línea modificada.
   ***(2.00 puntos)***

2. **Cobertura con el depurador.** Con la versión ya corregida de `Entrada.categoria`:
   - Ejecuta con el **depurador de VS Code** (puntos de ruptura en cada `return` y en el `throw`) los siguientes
     conjuntos de pruebas: **A = {30}**, **B = {30, 5, 70}** y **C = {30, 5, 70, -1}**. Anota para cada caso qué
     sentencia final se alcanza.
   - Calcula, para cada conjunto, la **cobertura de sentencias** y la **cobertura de decisiones**, considerando estas
     tres decisiones: D1 `(edad < 0 || edad > 120)`, D2 `(edad < 12)` y D3 `(edad < 65)`.
   - Propón un **conjunto mínimo** que alcance el 100% de cobertura de decisiones y explica por qué no puede tener
     menos casos.

   Entrega capturas del depurador, la tabla de resultados por conjunto y el razonamiento del conjunto mínimo.
   ***(2.50 puntos)***

3. **Conjetura de errores.** Para `CuentaBancaria`, considera que **no es válido** ningún valor que no sea un número
   finito (`NaN` o infinito). Crea la clase `PruebaConjetura` con un `main` que pruebe **al menos 6 entradas
   sospechosas**, por ejemplo: `new CuentaBancaria(Double.NaN)`, `ingresar(Double.NaN)`,
   `ingresar(Double.POSITIVE_INFINITY)`, `retirar(Double.NaN)`, diez ingresos de `0.1` comparando el saldo con `1.0`
   usando igualdad exacta, y dos ingresos de `Double.MAX_VALUE`. Indica el resultado esperado según la especificación,
   el obtenido y el estado de cada caso. Distingue entre **defectos reales** y **comportamientos propios de los
   números decimales**. Entrega el código, la salida y la clasificación. ***(2.50 puntos)***

## PARTE TEÓRICA (3 puntos)

5. Compara las pruebas de **caja blanca** y de **caja negra** (en qué se basan, qué ventajas tienen y qué limitaciones)
