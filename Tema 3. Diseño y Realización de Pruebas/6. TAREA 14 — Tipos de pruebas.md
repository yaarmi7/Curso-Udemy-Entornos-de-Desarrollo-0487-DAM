## Nueva clase para esta tarea

Añade al proyecto la clase `src/main/java/com/ejemplo/entradas/Entrada.java`:

```java
package com.ejemplo.entradas;

public class Entrada {

    public static String categoria(int edad) {
        if (edad < 0 || edad > 120) {
            throw new IllegalArgumentException("Edad no válida: " + edad);
        }
        if (edad <= 12) {
            return "INFANTIL";
        }
        if (edad < 65) {
            return "ADULTO";
        }
        return "JUBILADO";
    }
}
```

**Especificación de `categoria(int edad)`:**

- Las edades válidas van de **0 a 120** (ambas incluidas). Fuera de ese rango se lanza `IllegalArgumentException`.
- De **0 a 11** años devuelve `"INFANTIL"`.
- De **12 a 64** años devuelve `"ADULTO"`.
- De **65 a 120** años devuelve `"JUBILADO"`.
