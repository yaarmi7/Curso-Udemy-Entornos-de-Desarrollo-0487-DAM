## Código de partida

Añade la clase `src/main/java/com/ejemplo/facturacion/Factura.java`:

```java
package com.ejemplo.facturacion;

public class Factura {

    public double calcularTotal(double[] p, int[] c, String t) {
        double tt = 0;
        for (int i = 0; i < p.length; i++) {
            tt = tt + p[i] * c[i];
        }
        if (t.equals("VIP")) {
            tt = tt - tt * 0.15;
        } else if (t.equals("NORMAL")) {
            tt = tt - tt * 0.05;
        } else if (t.equals("NUEVO")) {
            tt = tt - tt * 0.0;
        }
        tt = tt + tt * 0.21;
        return tt;
    }
}
```

**Comportamiento actual que debe conservarse durante la refactorización:**

- El **subtotal** es la suma de `precio × cantidad` de cada línea.
- El **descuento** depende del tipo de cliente: `"VIP"` 15%, `"NORMAL"` 5%, `"NUEVO"` 0% y **cualquier otro tipo, 0%**.
- Sobre el importe con descuento se aplica un **IVA del 21%**.
- Con listas vacías el total es 0.
