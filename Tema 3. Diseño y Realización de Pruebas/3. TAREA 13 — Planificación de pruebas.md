## Punto de partida

siguiente `pom.xml`:

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0"

    <maven.compiler.source>17</maven.compiler.source>
    <maven.compiler.target>17</maven.compiler.target>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
  </properties>
</project>
```

Y la clase `src/main/java/com/ejemplo/banco/CuentaBancaria.java`:

```java
package com.ejemplo.banco;

public class CuentaBancaria {
    private double saldo;

    public CuentaBancaria(double saldoInicial) {
        if (saldoInicial < 0) {
            throw new IllegalArgumentException("El saldo inicial no puede ser negativo");
        }
        this.saldo = saldoInicial;
    }

    public void ingresar(double cantidad) {
        if (cantidad <= 0) {
            throw new IllegalArgumentException("La cantidad a ingresar debe ser positiva");
        }
        saldo += cantidad;
    }

    public void retirar(double cantidad) {
        if (cantidad <= 0) {
            throw new IllegalArgumentException("La cantidad a retirar debe ser positiva");
        }
        if (cantidad >= saldo) {
            throw new IllegalStateException("Saldo insuficiente");
        }
        saldo -= cantidad;
    }

    public double getSaldo() {
        return saldo;
    }
}
```

**Especificación de la clase** (esto es lo que debe cumplir, y es lo que debes usar para decidir los resultados
esperados):

- Una cuenta se crea con un saldo inicial **mayor o igual que 0**; si es negativo se lanza `IllegalArgumentException`.
- `ingresar(cantidad)` suma la cantidad al saldo. La cantidad debe ser **mayor que 0**; si no, se lanza
  `IllegalArgumentException`.
- `retirar(cantidad)` resta la cantidad del saldo. La cantidad debe ser **mayor que 0** (si no, se lanza
  `IllegalArgumentException`) y **no puede superar el saldo** disponible (si lo supera, se lanza
  `IllegalStateException`). Se puede retirar **exactamente** todo el saldo.
