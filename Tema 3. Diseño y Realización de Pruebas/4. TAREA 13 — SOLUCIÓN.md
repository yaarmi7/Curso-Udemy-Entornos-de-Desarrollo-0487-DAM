### Código de `PruebaManual`

```java
package com.ejemplo.banco;

public class PruebaManual {

    static void comprobar(String id, String descripcion, boolean correcto) {
        System.out.println(id + " | " + descripcion + " | " + (correcto ? "OK" : "FALLO"));
    }

    static boolean lanza(Class<? extends Exception> tipo, Runnable accion) {
        try {
            accion.run();
        } catch (Exception e) {
            return tipo.isInstance(e);
        }
        return false;
    }

    public static void main(String[] args) {
        comprobar("CP-01", "Crear cuenta con saldo 100",
                new CuentaBancaria(100).getSaldo() == 100);

        comprobar("CP-02", "Saldo inicial negativo",
                lanza(IllegalArgumentException.class, () -> new CuentaBancaria(-1)));

        comprobar("CP-03", "Saldo inicial 0",
                new CuentaBancaria(0).getSaldo() == 0);

        CuentaBancaria c4 = new CuentaBancaria(100);
        c4.ingresar(50);
        comprobar("CP-04", "Ingresar 50", c4.getSaldo() == 150);

        comprobar("CP-05", "Ingresar 0",
                lanza(IllegalArgumentException.class, () -> new CuentaBancaria(100).ingresar(0)));

        comprobar("CP-06", "Ingresar -10",
                lanza(IllegalArgumentException.class, () -> new CuentaBancaria(100).ingresar(-10)));

        CuentaBancaria c7 = new CuentaBancaria(100);
        c7.retirar(30);
        comprobar("CP-07", "Retirar 30 de 100", c7.getSaldo() == 70);

        boolean ok8;
        try {
            CuentaBancaria c8 = new CuentaBancaria(100);
            c8.retirar(100);
            ok8 = c8.getSaldo() == 0;
        } catch (Exception e) {
            ok8 = false;
        }
        comprobar("CP-08", "Retirar todo el saldo (100 de 100)", ok8);

        comprobar("CP-09", "Retirar 150 de 100",
                lanza(IllegalStateException.class, () -> new CuentaBancaria(100).retirar(150)));

        comprobar("CP-10", "Retirar 0",
                lanza(IllegalArgumentException.class, () -> new CuentaBancaria(100).retirar(0)));
    }
}
```

## 3. Detección y registro del defecto (2,50 puntos)

**Caso que falla:** CP-08 (retirar exactamente todo el saldo).

**Línea defectuosa:** en el método `retirar`, la condición

```java
if (cantidad >= saldo) {
```

debería ser

```java
if (cantidad > saldo) {
```

porque la especificación permite retirar exactamente todo el saldo y solo debe rechazarse una cantidad **superior**
al saldo.

### Informe de incidencia

| Campo                      | Contenido                                                                           |
| -------------------------- | ----------------------------------------------------------------------------------- |
| **ID de incidencia**       | INC-001                                                                             |
| **Título**                 | No es posible retirar todo el saldo de la cuenta                                    |
| **Componente**             | `CuentaBancaria.retirar(double)`                                                    |
| **Pasos para reproducir**  | 1. Crear `new CuentaBancaria(100)`. 2. Llamar a `retirar(100)`.                     |
| **Resultado esperado**     | La operación se realiza y `getSaldo()` devuelve 0                                   |
| **Resultado obtenido**     | Se lanza `IllegalStateException: Saldo insuficiente` y el saldo sigue siendo 100    |
| **Causa probable**         | Condición `cantidad >= saldo` en lugar de `cantidad > saldo` (error en el límite)   |
| **Gravedad**               | Alta: el cliente no puede vaciar su cuenta                                          |
| **Estado**                 | Abierta                                                                             |

**Criterios de corrección:** caso fallido identificado (0,50) · línea defectuosa localizada y causa explicada
(0,75) · informe con todos los campos (0,75) · pasos reproducibles y claros (0,50).

## 5. Error, defecto y fallo, y principios (1,50 puntos)

- **Error:** la equivocación humana. El programador escribió `>=` en lugar de `>` al implementar `retirar`.
- **Defecto:** la anomalía que queda en el código como consecuencia del error: la línea `if (cantidad >= saldo)`.
- **Fallo:** el comportamiento incorrecto observable al ejecutar el defecto: al retirar 100 de una cuenta con 100 se
  lanza una excepción en lugar de dejar el saldo en 0.

**Principio ilustrado:** *las pruebas muestran la presencia de defectos, no su ausencia*. Los diez casos han
permitido encontrar un defecto, pero eso no demuestra que no haya más. De hecho, esta clase tiene otros problemas con
valores especiales como `Double.NaN` que estos diez casos no revelan, y que se descubrirán en tareas posteriores
diseñando casos más cuidadosos. También se ilustra que **las pruebas exhaustivas son imposibles**: solo se pueden
probar unos pocos valores de entre todos los posibles.
