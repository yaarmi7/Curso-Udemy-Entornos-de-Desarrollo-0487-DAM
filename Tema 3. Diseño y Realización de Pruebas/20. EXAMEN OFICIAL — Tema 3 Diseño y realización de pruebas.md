# PARTE B — PRÁCTICA CON ORDENADOR (6 puntos)

## Código de partida

Se dispone de la clase `Notas`, que clasifica una nota numérica. Guarda este código tal cual en
`src/main/java/com/ejemplo/notas/Notas.java`:

```java
package com.ejemplo.notas;

public class Notas {

    public static String clasificar(double nota) {
        if (nota < 0 || nota > 10) {
            throw new IllegalArgumentException("Nota no válida: " + nota);
        }
        if (nota < 5) {
            return "SUSPENSO";
        }
        if (nota <= 7) {
            return "APROBADO";
        }
        if (nota < 9) {
            return "NOTABLE";
        }
        return "SOBRESALIENTE";
    }
}
```

**Especificación de `clasificar(double nota)`:**

- Las notas válidas van de **0 a 10**, ambas incluidas. Fuera de ese rango se lanza `IllegalArgumentException`.
- De **0 hasta menos de 5** → `"SUSPENSO"`.
- De **5 hasta menos de 7** → `"APROBADO"`.
- De **7 hasta menos de 9** → `"NOTABLE"`.
- De **9 a 10** → `"SOBRESALIENTE"`.

**Orden de trabajo recomendado:** ejercicio 4, ejercicio 5, ejercicio 6, ejercicio 7. En el ejercicio 7 el
repositorio se inicia **antes de corregir** ningún defecto.
