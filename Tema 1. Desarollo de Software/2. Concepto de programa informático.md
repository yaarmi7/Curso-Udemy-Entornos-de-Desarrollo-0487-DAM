# 1. Concepto de programa informático

Un **programa informático** es un conjunto estructurado de instrucciones que un ordenador puede interpretar y ejecutar 
para realizar una tarea específica. Estas instrucciones están escritas en un lenguaje de programación y deben seguir 
una sintaxis estricta para que puedan ser procesadas correctamente por el sistema.

Aunque esta definición parece simple, encierra una realidad compleja: un programa es la traducción formal de una 
solución lógica a un problema. Es el puente entre la intención humana y la capacidad de cálculo de la máquina.

## 1.1. Un programa como proceso y como entidad
Un programa puede entenderse desde dos perspectivas:

### A) Como entidad estática (archivo en disco)
Es el conjunto de instrucciones almacenadas en un archivo:
* un .py en Python,
* un .java en Java,
* un .cs en C#,
* un .c en C,
* un .exe en Windows,
* un binario ELF en Linux.

En este estado, el programa **no está haciendo nada**. Solo existe como texto o como binario.

### B) Como proceso dinámico (en ejecución)
Cuando el sistema operativo carga el programa en memoria y la CPU comienza a ejecutar sus instrucciones, 
el programa se convierte en un **proceso**.
Un proceso tiene:
* memoria asignada,
* un estado,
* recursos del sistema,
* permisos,
* hilos de ejecución.

Esta distinción es fundamental:

*Un programa es un archivo; un proceso es ese programa ejecutándose.*

## 1.2. ¿Cómo interpreta un ordenador un programa?
Un ordenador no entiende conceptos, intenciones ni lógica humana. Solo interpreta **instrucciones binarias** representadas 
mediante señales eléctricas. Para que un programa pueda ejecutarse, debe transformarse en una secuencia de instrucciones 
que la CPU pueda procesar.

Este proceso implica:
* **Memoria RAM**: donde se carga el programa y sus datos.
* **CPU**: que ejecuta las instrucciones una a una.
* **Sistema operativo**: que gestiona permisos, recursos y comunicación con periféricos.
* **Periféricos**: que permiten entrada y salida de información.

## 1.3. Relación del programa con los componentes del sistema
### CPU (Unidad Central de Procesamiento)
Es el componente que ejecuta las instrucciones del programa.

Cada instrucción del programa se convierte en una operación que la CPU reconoce: sumar, comparar, 
mover datos, saltar a otra instrucción, etc.

### Memoria RAM
El programa no se ejecuta desde el disco.

Primero debe cargarse en la RAM, donde la CPU puede acceder a él rápidamente.

La RAM almacena:
* el código del programa,
* las variables,
* la pila de ejecución,
* el heap (objetos, estructuras dinámicas).

### Sistema operativo
Es el intermediario entre el programa y el hardware.

Gestiona:
* procesos,
* memoria,
* permisos,
* archivos,
* comunicación con periféricos.

Sin sistema operativo, la mayoría de programas no podrían ejecutarse.

### Periféricos
Permiten que el programa interactúe con el mundo exterior:
* teclado, ratón, pantalla, impresora, red, almacenamiento externo.

## 1.4. ¿Qué hace que un programa funcione?
Para que un programa funcione correctamente, deben cumplirse tres condiciones:

**El código debe estar bien escrito**  
* Sin errores de sintaxis ni lógica.

**Debe poder traducirse a instrucciones que la CPU entienda**  
* Mediante compilación, interpretación o ejecución en máquina virtual.

**Debe ejecutarse en un entorno adecuado**  
* Sistema operativo compatible, librerías disponibles, permisos correctos.
