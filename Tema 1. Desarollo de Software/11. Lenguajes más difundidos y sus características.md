# 4. Lenguajes más difundidos y sus características
En el desarrollo de software actual existen cientos de lenguajes de programación, pero solo unos pocos
dominan la industria por su madurez, ecosistema, rendimiento o facilidad de uso.

Este apartado analiza los lenguajes más utilizados hoy en día, explicando **qué los hace relevantes, 
en qué contextos se usan y qué características técnicas los definen**.

## 4.1. Java
Java es uno de los lenguajes más influyentes de la historia moderna del software. Diseñado bajo el 
lema *“write once, run anywhere”*, se ejecuta en la JVM, lo que le otorga una portabilidad excepcional.

### Características principales
* **Orientado a objetos** de forma estricta.
* **Tipado estático** y seguro.
* **Ejecución** híbrida mediante bytecode.
* **Gran ecosistema**: Spring, Hibernate, Maven, Gradle.
* **Multiplataforma** gracias a la JVM.

### Usos habituales
* Aplicaciones empresariales.
* Backend de alta carga.
* Android (hasta la llegada de Kotlin).
* Sistemas bancarios y financieros.

## 4.2. Python
Python es uno de los lenguajes más populares por su sintaxis simple y su enorme ecosistema de librerías.

### Características principales
* **Interpretado**.
* **Tipado dinámico**.
* **Multiparadigma** (imperativo, OOP, funcional).
* **Sintaxis muy legible**.
* **Gran ecosistema científico**: NumPy, Pandas, TensorFlow.

### Usos habituales
* Inteligencia artificial y machine learning.
* Automatización y scripting.
* Backend web (Django, Flask).
* Ciencia de datos.

## 4.3. C#
C# es el lenguaje principal del ecosistema .NET. Combina potencia, seguridad y facilidad de uso.

### Características principales
* **Orientado a objetos**.
* **Tipado estático**.
* **Ejecución híbrida** mediante CLR.
* **Muy robusto** para aplicaciones empresariales.
* **Excelente soporte para videojuegos** con Unity.

### Usos habituales
* Aplicaciones de escritorio.
* Backend con ASP.NET.
* Videojuegos (Unity).
* Aplicaciones empresariales.

## 4.4. JavaScript
JavaScript es el lenguaje estándar del desarrollo web. Se ejecuta en navegadores y también en servidores gracias a Node.js.

### Características principales
* **Interpretado**.
* **Tipado dinámico**.
* **Multiparadigma** (imperativo, funcional, OOP prototípico).
* **Ejecución en navegador**.
* **Ecosistema enorme**: React, Angular, Vue, Node.js.

### Usos habituales
* Desarrollo web frontend.
* Backend con Node.js.
* Aplicaciones híbridas (Electron, React Native).
* Automatización de interfaces.

## 4.5. C++
C++ es uno de los lenguajes más potentes y de mayor rendimiento. Permite control total sobre la memoria y el hardware.

### Características principales
* **Compilado**.
* **Tipado estático**.
* **Orientado a objetos**, pero también imperativo.
* **Control manual de memoria**.
* **Rendimiento extremo**.

### Usos habituales
* Motores de videojuegos.
* Sistemas embebidos.
* Aplicaciones de alto rendimiento.
* Software de sistemas.

## 4.6. Kotlin
Kotlin es el lenguaje moderno del ecosistema JVM y el estándar actual para Android.

### Características principales
* **Tipado estático**.
* **Orientado a objetos + funcional**.
* **Sintaxis moderna y concisa**.
* **Interoperable con Java**.
* **Ejecución híbrida** en JVM.

### Usos habituales
* Desarrollo Android.
* Backend con Ktor o Spring.
* Aplicaciones multiplataforma (Kotlin Multiplatform).

## 4.7. Rust
Rust es un lenguaje moderno centrado en la seguridad y el rendimiento, sin necesidad de garbage collector.

### Características principales
* **Compilado**.
* **Tipado estático**.
* **Modelo de propiedad de memoria** (ownership).
* **Sin fugas de memoria**.
* **Rendimiento comparable a C++**.

### Usos habituales
* Sistemas embebidos.
* Desarrollo de motores y herramientas de bajo nivel.
* Aplicaciones de alta seguridad.
* Sustituto moderno de C/C++ en muchos proyectos.
