# TAREA 1 — SOLUCIÓN 
### Cómo intervienen la CPU, la RAM y el sistema operativo en la ejecución de un programa
**Ejemplo**: abrir un navegador web (Google Chrome).
## 1. Sistema operativo
Cuando el usuario hace doble clic en Chrome:
* El sistema operativo recibe el evento.
* Localiza el ejecutable (chrome.exe).
* Comprueba permisos y dependencias.
* Crea un **proceso** y le asigna memoria y recursos.

El sistema operativo es quien **autoriza, inicia y gestiona** la ejecución del programa.

## 2. Memoria RAM
Una vez creado el proceso:
* El ejecutable se **carga en la RAM**.
* Se reservan zonas de memoria:
  * **Stack** (funciones, variables locales)
  * **Heap** (objetos, estructuras dinámicas)
  *  **Datos del programa**
La RAM permite que la CPU acceda al programa **rápidamente**, ya que la CPU no trabaja directamente con el disco.

## 3. CPU
Cuando el programa está en memoria:
* La CPU empieza a ejecutar instrucciones del navegador.
* Procesa:
  * renderizado de la interfaz,
  * carga de pestañas,
  * ejecución de JavaScript,
  * animaciones,
  * eventos del usuario.

La CPU es quien **realmente ejecuta** el programa, instrucción por instrucción.

## Resumen aplicado al ejemplo
Abrir Chrome implica:
1. El sistema operativo crea el proceso.
2. La RAM carga el programa y sus datos.
3. La CPU ejecuta las instrucciones y muestra la ventana del navegador.
