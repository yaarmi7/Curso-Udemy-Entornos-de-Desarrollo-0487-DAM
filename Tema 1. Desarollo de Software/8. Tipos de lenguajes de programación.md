# 3. Tipos de lenguajes de programación
Los lenguajes de programación se pueden clasificar según distintos criterios. Esta clasificación es esencial
para entender cómo se comporta un programa, cómo se ejecuta y qué herramientas necesita.

Cada lenguaje tiene un propósito, un modelo de ejecución y un paradigma que influye directamente en la forma
en que se desarrolla software.

## 3.1. Clasificación según el método de ejecución
Esta es la clasificación más importante desde el punto de vista técnico, porque determina **cómo se transforma 
el código fuente en algo que la máquina pueda ejecutar.**

### A) Lenguajes compilados
El código fuente se traduce completamente a código máquina antes de ejecutarse.

Ejemplos:
* C
* C++
* Rust
* Go

Características:
* Muy rápidos en ejecución.
* Dependientes del sistema operativo y la arquitectura.
* Generan ejecutables nativos.

Uso típico:
* Sistemas embebidos
* Motores de videojuegos
* Aplicaciones de alto rendimiento

### B) Lenguajes interpretados
El código se ejecuta línea a línea mediante un intérprete, sin generar un ejecutable nativo.

Ejemplos:
* Python
* JavaScript
* PHP
* Ruby

Características:
* Más lentos que los compilados.
* Muy flexibles.
* Portabilidad alta (si el intérprete está disponible).

Uso típico:
* Scripts
* Automatización
* Desarrollo web

### C) Lenguajes híbridos (compilación + máquina virtual)
Generan bytecode, que se ejecuta en una máquina virtual.

Ejemplos:
* Java (JVM)
* C# (CLR)
* Kotlin (JVM)

Características:
* Portabilidad total entre sistemas.
* Optimización dinámica (JIT).
* Seguridad y gestión automática de memoria.

Uso típico:
* Aplicaciones empresariales
* Android
* Videojuegos con Unity (C#)

## 3.2. Clasificación según el paradigma
El paradigma define **cómo se estructura el pensamiento del programador** y cómo se organiza el código.

### A) Imperativos
El programador indica *cómo* se debe hacer algo, paso a paso.

Ejemplos:
* C
* Python (parcialmente)
* Java (parcialmente)

### B) Orientados a objetos
Organizan el código en clases y objetos que representan entidades del mundo real.

Ejemplos:
* Java
* C#
* Python (parcialmente)
* C++

Conceptos clave:
* clases
* objetos
* herencia
* polimorfismo
* encapsulación

### C) Funcionales
Basados en funciones puras y ausencia de estado mutable.

Ejemplos:
* Haskell
* Scala
* Elixir
* JavaScript (parcialmente)

### D) Lógicos
Basados en reglas y relaciones.

Ejemplo:
* Prolog

## 3.3. Clasificación según el tipado
El tipado define cómo se gestionan los tipos de datos.

### A) Tipado estático
El tipo de cada variable se conoce en tiempo de compilación.

Ejemplos:
* Java
* C#
* C
* C++
* Rust

Ventajas:
* Menos errores en ejecución.
* Mejor rendimiento.

### B) Tipado dinámico
El tipo se determina en tiempo de ejecución.

Ejemplos:
* Python
* JavaScript
* Ruby

Ventajas:
* Mayor flexibilidad.
* Desarrollo más rápido.

## 3.4. Clasificación según el nivel de abstracción

### A) Lenguajes de bajo nivel
Cercanos al hardware.

Ejemplos:
* Ensamblador
* C (parcialmente)

### B) Lenguajes de alto nivel
Cercanos al lenguaje humano.

Ejemplos:
* Python
* Java
* C#

## 3.5. Por qué es importante esta clasificación
Conocer estas diferencias permite:
* elegir el lenguaje adecuado para cada proyecto,
* entender cómo se ejecutará el programa,
* saber qué herramientas se necesitan,
* anticipar problemas de rendimiento,
* comprender el comportamiento del código.
