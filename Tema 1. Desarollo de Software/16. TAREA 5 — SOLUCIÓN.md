# TAREA 5 — SOLUCIÓN 
**Aplicación del ciclo de vida del software a un proyecto real: Sistema de gestión de biblioteca.**

## 1. Requisitos funcionales
* Registrar libros (alta, baja, modificación).
* Registrar usuarios.
* Prestar y devolver libros.
* Consultar disponibilidad.
* Generar informes básicos.

### Requisitos no funcionales
* Interfaz sencilla.
* Seguridad básica (login).
* Rendimiento suficiente para consultas rápidas.
* Base de datos persistente.

## 2. Diseño básico
* Diagrama de clases (conceptual):
  * Clase Libro
  * Clase Usuario
  * Clase Prestamo
  * Clase Biblioteca como gestor
* Diagrama de casos de uso:
  * “Registrar libro”, “Prestar libro”, “Devolver libro”, “Consultar catálogo”.

## 3. Tecnologías y lenguajes
* **Backend**: Java o Python.
* **Base de datos**: MySQL o SQLite.
* **Interfaz**: JavaFX, HTML+CSS o una API REST con frontend simple.
* **Control de versiones**: Git.

## 4. Tipos de pruebas necesarias
* **Unitarias**: comprobar métodos de Libro, Usuario, Prestamo.
* **Integración**: comprobar flujo completo de préstamo.
* **Funcionales**: validar que cada caso de uso funciona.
* **Regresión**: asegurar que nuevas funciones no rompen las anteriores.

## 5. Documentación
* Manual técnico (clases, API, base de datos).
* Manual de usuario (cómo registrar, prestar, devolver).
* Comentarios en el código.
* Diagrama UML actualizado.

## 6. Despliegue
* Instalación del programa en el equipo del bibliotecario.
* Configuración de la base de datos.
* Creación de usuario administrador.
* Prueba inicial de funcionamiento.

## 7. Mantenimiento
* Corrección de errores detectados.
* Actualización de dependencias.
* Añadir nuevas funciones (por ejemplo, reservas).
* Optimización de consultas si la base de datos crece.
