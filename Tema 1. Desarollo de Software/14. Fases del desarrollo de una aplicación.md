# 5. Fases del desarrollo de una aplicación
El desarrollo de software no es simplemente escribir código. Es un proceso estructurado que sigue una serie 
de fases que permiten transformar una idea en un producto funcional, mantenible y escalable.

Estas fases forman el **ciclo de vida del software**, y conocerlas es esencial para cualquier desarrollador profesional.

## 5.1. Fase de análisis
La fase de análisis consiste en **comprender el problema** y definir qué debe hacer la aplicación.

Aquí se identifican:
* requisitos funcionales (qué debe hacer el sistema),
* requisitos no funcionales (rendimiento, seguridad, usabilidad),
* actores del sistema,
* restricciones técnicas,
* alcance del proyecto.

El resultado del análisis suele ser un documento de requisitos o un backlog inicial.

## 5.2. Fase de diseño
En esta fase se define **cómo se va a construir** la aplicación.

Incluye:
* arquitectura del sistema,
* diagramas UML (clases, casos de uso, secuencia),
* estructura de módulos,
* tecnologías a utilizar,
* diseño de base de datos,
* interfaces y flujos de usuario.

El diseño sirve como plano para la fase de codificación.

## 5.3. Fase de codificación
Es la fase donde se escribe el **código fuente** siguiendo el diseño previo.

Aquí se utilizan:
* lenguajes de programación,
* entornos de desarrollo (IDE),
* librerías y frameworks,
* control de versiones (Git).

La calidad del código depende de:
* buenas prácticas,
* modularidad,
* claridad,
* documentación,
* pruebas unitarias.

## 5.4. Fase de pruebas
El objetivo es **verificar que el software funciona correctamente**.

Tipos de pruebas:
* pruebas unitarias,
* pruebas de integración,
* pruebas funcionales,
* pruebas de regresión,
* pruebas de rendimiento.

Las pruebas detectan errores antes de que el software llegue al usuario final.

## 5.5. Fase de documentación
La documentación es esencial para que otros desarrolladores, usuarios o empresas puedan entender y utilizar el software.
Incluye:
* comentarios en el código,
* manuales técnicos,
* guías de usuario,
* documentación de API,
* diagramas actualizados.

Un software sin documentación es difícil de mantener.

## 5.6. Fase de explotación (despliegue)
Consiste en **poner el software en producción** para que los usuarios puedan utilizarlo.

Incluye:
* instalación,
* configuración,
* despliegue en servidores,
* publicación en tiendas (Android, iOS),
* monitorización.

Es una fase crítica porque el software empieza a interactuar con usuarios reales.

## 5.7. Fase de mantenimiento
El mantenimiento es continuo y puede durar años.

Incluye:
* corrección de errores,
* mejoras,
* actualizaciones,
* adaptación a nuevas tecnologías,
* optimización.

El mantenimiento suele ser la fase más larga del ciclo de vida.

## 5.8. Relación entre fases
Aunque se presentan de forma secuencial, en la práctica suelen solaparse.

Metodologías como **Scrum** o **Kanban** trabajan estas fases de forma iterativa.
