# TAREA 2 — SOLUCIÓN 
**Tema**: Código fuente, código objeto, ejecutable y bytecode.

## 1. Código fuente
Es el texto que escribe el programador en un lenguaje de programación.

Ejemplo: main.c, App.java, script.py.

Es legible por humanos, pero **no ejecutable** por la CPU.

## 2. Código objeto
Es el resultado de la primera fase de la compilación.

Contiene instrucciones en lenguaje máquina, pero **no forma un programa completo**.

Ejemplo: main.o en C.

## 3. Código ejecutable
Es el archivo final que el sistema operativo puede ejecutar directamente.

Ejemplo: program.exe en Windows, binarios ELF en Linux.

Incluye todas las instrucciones necesarias para que la CPU lo ejecute.

## 4. Bytecode
Es un código intermedio generado por lenguajes híbridos.

No es ejecutable por la CPU directamente.

Ejemplo:
* Java → genera .class (bytecode)
* C# → genera IL (Intermediate Language)

## 5. Diferencias entre ejecutable nativo y bytecode
| Característica | Ejecutable nativo | Bytecode |
| -------------- | ----------------- | -------- |
| Se ejecuta directamente | Sí | No |
| Requiere máquina virtual | No | Sí |
| Portabilidad | Baja | Alta |
| Optimización | Depende del compilador | JIT en tiempo de ejecución |

## 6. Ventajas de usar máquinas virtuales (JVM / CLR)
* Portabilidad entre sistemas operativos.
* Seguridad y aislamiento del programa.
* Gestión automática de memoria (GC).
* Optimización dinámica mediante JIT.
* Menor dependencia del hardware específico.
### Ejemplo real aplicado

*Lenguaje compilado (C)**
* main.c → compilador → main.o → enlazador → program.exe
* El ejecutable se ejecuta directamente en la CPU.

**Lenguaje híbrido (Java)**
* App.java → compilador → App.class (bytecode)
* La JVM interpreta/optimiza ese bytecode y lo ejecuta en cualquier sistema.
