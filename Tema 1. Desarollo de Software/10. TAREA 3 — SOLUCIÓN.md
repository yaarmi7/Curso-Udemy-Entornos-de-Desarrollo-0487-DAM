# TAREA 3 — SOLUCIÓN
**Clasificación de lenguajes según ejecución, paradigma, tipado y nivel de abstracción.**

## 1. Java
* **Ejecución**: Híbrido (bytecode en JVM)
* **Paradigma**: Orientado a objetos
* **Tipado**: Estático
* **Abstracción**: Alto nivel

## 2. Python
* **Ejecución**: Interpretado
* **Paradigma**: Multiparadigma (imperativo, OOP, funcional)
* **Tipado**: Dinámico
* **Abstracción**: Alto nivel

## 3. C
* **Ejecución**: Compilado
* **Paradigma**: Imperativo
* **Tipado**: Estático
* **Abstracción**: Bajo nivel (comparado con otros lenguajes modernos)

## 4. JavaScript
* **Ejecución**: Interpretado
* **Paradigma**: Multiparadigma (imperativo, funcional, OOP prototípico)
* **Tipado**: Dinámico
* **Abstracción**: Alto nivel
## 5. C#
* **Ejecución**: Híbrido (bytecode IL en CLR)
* **Paradigma**: Orientado a objetos
* **Tipado**: Estático
* **Abstracción**: Alto nivel

## 6. Kotlin
* **Ejecución**: Híbrido (JVM)
* **Paradigma**: Orientado a objetos + funcional
* **Tipado**: Estático
* **Abstracción**: Alto nivel

## 7. Rust
* **Ejecución**: Compilado
* **Paradigma**: Imperativo + funcional
* **Tipado**: Estático
* **Abstracción**: Medio-alto (más alto que C, más bajo que Java/Python)
