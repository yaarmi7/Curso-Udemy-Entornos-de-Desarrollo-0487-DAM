# INTRODUCCIÓN AL TEMA 1 — DESARROLLO DE SOFTWARE
El desarrollo de software es una disciplina central en la informática moderna. Todo lo que hacemos con un ordenador, 
un móvil, una consola o incluso un electrodoméstico inteligente depende de programas diseñados, escritos y mantenidos 
por desarrolladores. Desde aplicaciones empresariales que gestionan miles de transacciones por segundo hasta videojuegos, 
sistemas embebidos o servicios web globales, el software es el motor invisible que sostiene la tecnología contemporánea.

Comprender cómo se crea ese software es esencial para cualquier técnico o desarrollador. 
No basta con saber programar: es necesario entender **qué es un programa**, cómo se relaciona con el hardware, 
cómo se transforma el código fuente en un ejecutable, qué tipos de lenguajes existen, qué herramientas intervienen y 
cuáles son las fases que componen el ciclo de vida del desarrollo.

Este primer tema establece los fundamentos que acompañarán al estudiante durante todo el ciclo formativo. 
Aquí se construye la base conceptual que permitirá, más adelante, dominar entornos de desarrollo, realizar pruebas, 
refactorizar código, documentar proyectos y generar diagramas UML. Sin esta base, el resto del módulo carecería de estructura.

## El software como puente entre la lógica humana y la máquina
Un ordenador no entiende ideas, intenciones ni conceptos abstractos. Solo interpreta instrucciones extremadamente precisas 
representadas mediante señales eléctricas. El software actúa como un puente entre la lógica humana y la capacidad de cálculo 
de la máquina. Para que ese puente funcione, el programador debe escribir código en un lenguaje que pueda ser traducido a 
instrucciones que la CPU pueda ejecutar.

Este proceso de traducción —compilación, interpretación o ejecución en máquinas virtuales— es uno de los pilares 
del desarrollo de software. Entenderlo permite comprender por qué un programa funciona, por qué falla y cómo optimizarlo.

## El papel del hardware en la ejecución del software
Aunque este tema se centra en el software, es imposible separarlo del hardware. Un programa no existe en el vacío: 
necesita memoria para almacenarse, un procesador para ejecutarse, periféricos para interactuar y un sistema operativo 
que gestione recursos y permisos.

La relación entre software y hardware es tan estrecha que muchos errores, optimizaciones y decisiones de diseño dependen 
de cómo funciona internamente un sistema informático. Por eso, antes de hablar de lenguajes o herramientas, 
es necesario comprender esta relación.

## Lenguajes, paradigmas y modelos de ejecución
El desarrollo de software no se limita a escribir código. Existen múltiples lenguajes, cada uno con sus características, 
paradigmas y modelos de ejecución. Algunos se compilan, otros se interpretan, otros generan bytecode para máquinas virtuales. 
Algunos son orientados a objetos, otros funcionales, otros imperativos.

Conocer estas diferencias permite elegir el lenguaje adecuado para cada proyecto y entender cómo se comportará el programa 
durante su ejecución.

## El ciclo de vida del software: más allá de programar
Crear software no es solo escribir código. Es un proceso estructurado que incluye:
* análisis,
* diseño,
* codificación,
* pruebas,
* documentación,
* despliegue,
* mantenimiento.

Cada fase tiene objetivos, herramientas y metodologías específicas. Un desarrollador profesional debe dominar este ciclo 
para garantizar que el software sea funcional, seguro, mantenible y escalable.

## De código fuente a ejecutable: el viaje del programa
Una de las partes más técnicas del tema es comprender cómo se transforma el código fuente en un ejecutable. 
Este proceso implica compiladores, intérpretes, enlazadores, máquinas virtuales y sistemas de construcción. 
Entenderlo es fundamental para diagnosticar errores, optimizar rendimiento y trabajar con diferentes lenguajes.

## Objetivo del Tema 1
Al finalizar este tema, el estudiante será capaz de:
* Comprender qué es un programa informático y cómo se ejecuta.
* Diferenciar código fuente, objeto y ejecutable.
* Entender el funcionamiento de compiladores, intérpretes y máquinas virtuales.
* Clasificar lenguajes de programación según diferentes criterios.
* Identificar y explicar las fases del desarrollo de software.
* Describir el proceso completo de generación de un ejecutable.

Este conocimiento será imprescindible para abordar los siguientes temas del módulo.
