# TAREA 4 — SOLUCIÓN
**Lenguajes más adecuados para distintos tipos de desarrollo + justificación técnica + ejemplo real.**

## 1. Desarrollo web
**Lenguaje adecuado**: JavaScript

**Justificación técnica**:
Es el único lenguaje que se ejecuta nativamente en navegadores y tiene un ecosistema enorme para frontend y backend (Node.js).

**Ejemplo real**:
Facebook usa React (JavaScript) en su interfaz web.

## 2. Aplicaciones empresariales
**Lenguaje adecuado**: Java

**Justificación técnica**:
Robusto, seguro, multiplataforma y con frameworks empresariales como Spring.

**Ejemplo real**:
La mayoría de bancos europeos utilizan Java en sus sistemas internos.

## 3. Videojuegos
**Lenguaje adecuado**: C#

**Justificación técnica**:
Es el lenguaje principal de Unity, uno de los motores más usados en la industria.

**Ejemplo real**:
El videojuego Hollow Knight está desarrollado con Unity (C#).

## 4. Sistemas embebidos
**Lenguaje adecuado**: C++

**Justificación técnica**:
Permite control total del hardware y gestión manual de memoria, imprescindible en dispositivos con recursos limitados.

**Ejemplo real**:
El firmware de Arduino está escrito en C++.

## 5. Inteligencia artificial
**Lenguaje adecuado**: Python

**Justificación técnica**:
Tiene las librerías más potentes para IA y ciencia de datos (TensorFlow, PyTorch, NumPy).

**Ejemplo real**:
Google utiliza Python en muchos proyectos de machine learning.
