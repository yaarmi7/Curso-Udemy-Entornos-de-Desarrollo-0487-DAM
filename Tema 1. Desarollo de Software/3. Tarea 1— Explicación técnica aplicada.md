# Tarea 1— Explicación técnica aplicada
Redacta un texto explicando **cómo intervienen la CPU, la RAM y el sistema operativo** en la ejecución de un programa.

Incluye un ejemplo real, por ejemplo:
* abrir un navegador web,
* ejecutar un videojuego,
* iniciar una aplicación de escritorio.

Tu explicación debe incluir:
* qué ocurre cuando haces doble clic en el programa,
* cómo se carga en memoria,
* cómo la CPU procesa las instrucciones,
* cómo el sistema operativo gestiona el proceso.
