# EXAMEN OFICIAL — Tema 1: Desarrollo de Software

**Duración**: 110 minutos

**Puntuación total**: 10 puntos

**Nivel**: Módulo 0487 – Entornos de Desarrollo

## EJERCICIO 1 
Un usuario afirma que “un programa es solo un archivo que está en el ordenador”. A partir de esta afirmación, 
explica qué es realmente un programa informático y cómo se ejecuta dentro de un sistema. **Total: 1,5 puntos**

a) Explica qué es un programa como entidad estática (archivo). **(0,4 puntos)**

b) Explica qué es un programa como proceso en ejecución. **(0,4 puntos)**

c) Describe el papel de la CPU en la ejecución del programa. **(0,35 puntos)**

d) Describe el papel de la RAM en la ejecución del programa. **(0,35 puntos)**

## EJERCICIO 2 
Un estudiante confunde los distintos tipos de código que intervienen en el desarrollo de software. 
Debes redactar una explicación clara que le permita diferenciar cada uno y entender su función 
en el proceso de construcción de un programa. **Total: 1,5 puntos**

a) Define código fuente y pon un ejemplo. **(0,4 puntos)**

b) Define código objeto y explica por qué no es ejecutable. **(0,4 puntos)**

c) Define código ejecutable y pon un ejemplo según el sistema operativo. **(0,35 puntos)**

d) Explica qué es el bytecode y en qué lenguajes aparece. **(0,35 puntos)**

## EJERCICIO 3 
En un proyecto se utilizan distintos lenguajes y el equipo necesita entender cómo se ejecuta cada uno. 
Debes explicar las diferencias entre compilación, interpretación y ejecución en máquina virtual. **Total: 1,5 puntos**

a) Explica qué hace un compilador y qué archivo genera. **(0,4 puntos)**

b) Explica qué hace un intérprete y cómo ejecuta el código. **(0,4 puntos)**

c) Explica qué es una máquina virtual y cómo ejecuta el bytecode. **(0,35 puntos)**

d) Indica una ventaja técnica de usar máquinas virtuales. **(0,35 puntos)**

## EJERCICIO 4 
Clasifica los siguientes lenguajes según distintos criterios técnicos. No es necesario justificar, 
solo clasificar correctamente. **Total: 1 punto**

Lenguajes: **Java, Python, C, JavaScript, C#, Kotlin, Rust**

a) Clasificación según método de ejecución (compilado, interpretado, híbrido). **(0,25 puntos)**

b) Clasificación según paradigma principal. **(0,25 puntos)**

c) Clasificación según tipado (estático o dinámico). **(0,25 puntos)**

d) Clasificación según nivel de abstracción (alto, medio, bajo). **(0,25 puntos)**

## EJERCICIO 5 :

## EJERCICIO 6 
Un alumno quiere entender cómo se transforma el código fuente en un ejecutable dentro de un entorno de desarrollo. 
Describe el proceso completo de forma clara y ordenada. **Total: 1,5 puntos**

a) Explica qué ocurre en la fase de compilación. **(0,4 puntos)**

b) Explica qué ocurre en la fase de enlace. **(0,4 puntos)**

c) Indica qué archivos se generan en cada fase. **(0,35 puntos)**

d) Explica la diferencia entre ejecutable nativo y bytecode. **(0,35 puntos)**

## EJERCICIO 7 
Un centro educativo quiere desarrollar una aplicación web para gestionar las reservas de las aulas de informática. 
El jefe de proyecto te pide que describas cómo aplicarías las fases del ciclo de vida del software a este proyecto, 
de forma práctica y concreta, como si fuera un caso real. **Total: 2 puntos**

a) Fase de análisis: describe al menos tres requisitos funcionales y dos no funcionales para 
la aplicación de reservas. **(0,5 puntos)**

b) Fase de diseño: explica cómo organizarías la aplicación (módulos principales, base de 
datos, interfaz básica). **(0,5 puntos)**

c) Fase de codificación y pruebas: indica qué tipo de tecnologías usarías (sin entrar en 
programación detallada) y qué tipos de pruebas aplicarías antes de poner la aplicación en uso. **(0,5 puntos)**

d) Fase de despliegue y mantenimiento: describe cómo pondrías la aplicación en producción y 
qué tareas de mantenimiento serían necesarias durante el curso escolar. **(0,5 puntos)**

## EJERCICIO OPCIONAL EXTRA 
Una empresa tecnológica quiere desarrollar una aplicación interna para gestionar incidencias de sus empleados. 
El director técnico te pide que prepares un informe técnico donde se describa **todo el proceso que sigue el software 
desde que se escribe el código hasta que se ejecuta**, incluyendo **tipos de código, herramientas de ejecución, 
clasificación del lenguaje elegido, y fases del desarrollo del software**.

Tu informe debe ser claro, ordenado y demostrar que entiendes cómo funciona el ciclo completo de creación 
y ejecución de un programa. **Total: 1,5 puntos**

a) Explica qué papel tienen el **código fuente**, el **código objeto**, el **ejecutable** y el **bytecode** en 
el desarrollo de la aplicación. **(0,4 puntos)**

b) Describe cómo intervienen **compiladores**, **intérpretes** y **máquinas virtuales** en el 
proceso, indicando qué herramienta se usaría según el lenguaje elegido. **(0,3 puntos)**

c) Elige un lenguaje (Java, Python, C#, C, JavaScript, Kotlin o Rust) y clasifícalo según:
* método de ejecución,
* paradigma,
* tipado,
* nivel de abstracción.

**(0,3 puntos)**

d) Describe cómo se aplicarían las **fases del ciclo de vida del software** (análisis, diseño, 
codificación, pruebas, documentación, despliegue y mantenimiento) al proyecto de gestión de 
incidencias. **(0,3 puntos)**

e) Explica paso a paso cómo se obtiene el ejecutable final dentro de un entorno de desarrollo 
(IDE), indicando qué archivos se generan en cada fase. **(0,2 puntos)**
