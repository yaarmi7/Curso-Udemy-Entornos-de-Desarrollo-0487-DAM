# TAREA 6 — SOLUCIÓN

**Proceso completo desde el código fuente hasta el ejecutable (C y Java).**

## 1. Qué hace el compilador
El compilador **traduce el código fuente** a un formato más cercano al lenguaje máquina.
* En C: genera código objeto (.o).
* En Java: genera bytecode (.class).

También detecta errores de sintaxis y tipos.

## 2. Qué hace el enlazador
El enlazador (linker):
* une todos los archivos objeto,
* añade librerías necesarias,
* resuelve símbolos externos,
* genera el ejecutable final.

Solo existe en lenguajes compilados a nativo (como C).

## 3. Archivos generados en cada fase
### En C
* main.c → compilador → main.o
* main.o + librerías → enlazador → program.exe (Windows) o binario ELF (Linux)

### En Java
* App.java → compilador → App.class (bytecode)
* El bytecode se ejecuta en la JVM (no hay enlazador)

## 4. Diferencias entre ejecutable nativo y bytecode
| Característica | Ejecutable nativo (C) | Bytecode (Java) |
| -------------- | --------------------- | --------------- |
| Se ejecuta directamente | Sí | No |
| Requiere máquina virtual | No | Sí (JVM) |
| Portabilidad | Baja | Alta |
| Optimización | Depende del compilador | JIT en tiempo real |

## 5. Ejemplo real en C
* Archivo: main.c
* Compilación: gcc main.c -o programa
* Resultado: programa (ejecutable nativo)
* Se ejecuta directamente en la CPU.

## 6. Ejemplo real en Java
* Archivo: App.java
* Compilación: javac App.java
* Resultado: App.class (bytecode)
* Ejecución: java App
La JVM interpreta/optimiza el bytecode.
