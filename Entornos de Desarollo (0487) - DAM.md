# Curso Udemy: Entornos de Desarrollo (0487) – DAM

## Propuesta de valor
Este curso prepara al estudiante para dominar los entornos de desarrollo modernos, 
comprender el ciclo completo de creación de software, realizar pruebas, refactorizar código, 
documentar proyectos y generar diagramas UML. Está alineado al 100% con el módulo 
oficial **0487 – Entornos de Desarrollo** del ciclo **DAM**.

# Estructura del Curso (50 horas)
Organizado en **6 secciones**, siguiendo los contenidos oficiales.

## SECCIÓN 1 — Desarrollo de Software (8 horas)
### Objetivo
Comprender qué es un programa, cómo se transforma el código fuente en ejecutable, 
los tipos de lenguajes y las fases del desarrollo.
### Lecciones
#### Qué es un programa informático  
1. Concepto, relación con memoria, CPU, periféricos.
#### Código fuente, objeto y ejecutable 
2. Compilación, linking, máquinas virtuales, bytecode.
#### Tipos de lenguajes de programación  
3. Compilados, interpretados, híbridos, tipado, paradigmas.
#### Lenguajes más difundidos  
4. Java, Python, C#, JavaScript, C++.
#### Fases del desarrollo de software  
5. Análisis, diseño, codificación, pruebas, documentación, mantenimiento.
#### Cómo se genera un ejecutable  
6. Herramientas: compiladores, intérpretes, build systems.

## SECCIÓN 2 — Instalación y Uso de Entornos de Desarrollo (10 horas)
### Objetivo
Dominar la instalación, configuración y personalización de IDEs.
### Lecciones
#### Qué es un entorno de desarrollo  
1. Funciones, ventajas, componentes.
#### Instalación de IDEs 
2. VS Code, IntelliJ, Eclipse, NetBeans.
#### Extensiones y módulos  
3. Añadir, eliminar, configurar.
#### Automatización del entorno  
4. Snippets, tareas, linters, formatters.
#### Generación de ejecutables  
5. Java, Python, C#, C++.
#### Comparativa de IDEs  
6. Ventajas, desventajas, casos de uso.

## SECCIÓN 3 — Diseño y Realización de Pruebas (10 horas)
### Objetivo
Aprender a diseñar pruebas, depurar código y usar herramientas de testing.
### Lecciones
#### Tipos de pruebas  
1. Funcionales, estructurales, regresión, integración.
#### Casos de prueba  
2. Valores límite, clases de equivalencia.
#### Herramientas de depuración  
3. Breakpoints, inspección, seguimiento.
#### Pruebas unitarias  
4. JUnit, PyTest, NUnit.
#### Pruebas automáticas  
5. Pipelines, scripts, CI/CD básico.
#### Documentación de incidencias  
6. Reportes, seguimiento, herramientas.

## SECCIÓN 4 — Optimización y Documentación (8 horas)
### Objetivo
Refactorizar código, usar analizadores, documentar y controlar versiones.
### Lecciones
#### Patrones de refactorización  
1. Extract method, rename, inline, simplify.
#### Analizadores de código  
2. SonarLint, ESLint, Pylint.
#### Control de versiones  
3. Git, repositorios, branching.
#### Documentación  
4. Javadoc, docstrings, comentarios.

## SECCIÓN 5 — Diagramas de Clases (7 horas)
### Objetivo
Crear diagramas UML de clases y generar código.
### Lecciones
#### Conceptos de POO  
1. Clases, objetos, atributos, métodos.
#### Relaciones entre clases  
2. Herencia, composición, agregación.
#### Notación UML  
3. Símbolos, visibilidad, estructura.
#### Herramientas UML  
4. StarUML, PlantUML, módulos de IDE.
#### Generación de código  
5. Ingeniería directa.
#### Ingeniería inversa  
6. UML desde código existente.

## SECCIÓN 6 — Diagramas de Comportamiento (7 horas)
### Objetivo
Crear diagramas de casos de uso, secuencia, colaboración, actividades y estados.
### Lecciones
#### Tipos de diagramas de comportamiento  
1. Casos de uso, secuencia, aActividades, estados.
#### Casos de uso  
2. Actores, escenarios, relaciones.
#### Diagramas de interacción  
3. Secuencia y colaboración.
#### Diagramas de actividades  
4. Flujo, decisiones, nodos.
#### Diagramas de estados  
5. Estados, transiciones, eventos.

## Proyecto Final del Curso
Desarrollar un mini‑proyecto completo:
* Documentación inicial
* Diagrama de clases
* Diagramas de comportamiento
* Código funcional
* Pruebas unitarias
* Refactorización
* Control de versiones
* Documentación final
