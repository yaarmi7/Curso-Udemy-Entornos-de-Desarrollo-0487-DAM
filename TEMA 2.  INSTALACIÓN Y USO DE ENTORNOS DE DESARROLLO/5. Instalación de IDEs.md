# 2. Instalación de IDEs
La instalación de un entorno de desarrollo es el primer paso para poder trabajar de forma profesional con cualquier lenguaje 
de programación. Aunque cada IDE tiene sus particularidades, todos comparten un proceso similar: descarga, instalación, 
configuración inicial y creación de un proyecto. Dominar este proceso es fundamental, porque un IDE mal instalado o 
mal configurado puede generar errores, impedir la ejecución del programa o limitar funcionalidades esenciales como la 
depuración o el autocompletado.

En el ámbito profesional, los desarrolladores trabajan con distintos IDEs según el lenguaje, el tipo de proyecto o las 
preferencias del equipo. Por ello, este apartado se centra en los cuatro entornos más utilizados en el módulo: Visual Studio 
Code, IntelliJ IDEA, Eclipse y NetBeans. Cada uno ofrece ventajas específicas y requiere una instalación adecuada para 
funcionar correctamente.

## 2.1. Instalación de Visual Studio Code (VS Code)
Visual Studio Code es un editor ligero y modular que se convierte en un IDE completo gracias a sus extensiones. 
Su instalación es sencilla y rápida, lo que lo convierte en una herramienta ideal para estudiantes y profesionales.

### Pasos de instalación
1. Descargar VS Code desde la página oficial.
2. Ejecutar el instalador y seleccionar configuración por defecto.
3. Abrir VS Code y acceder al Marketplace de extensiones.
4. Instalar extensiones según el lenguaje (Java, Python, C/C++, HTML/CSS…).
5. Configurar el entorno de trabajo (tema, atajos, paneles).

## Requisitos adicionales
* Para Java: instalar JDK.
* Para Python: instalar Python desde su web oficial.
* Para C/C++: instalar compiladores (GCC, Clang o MSVC).

VS Code destaca por su flexibilidad: se adapta a cualquier lenguaje y proyecto.

## 2.2. Instalación de IntelliJ IDEA
IntelliJ IDEA es uno de los IDEs más potentes del mercado, especialmente diseñado para Java y Kotlin. 
Su instalación requiere algunos pasos adicionales debido a la necesidad de configurar el JDK.

### Pasos de instalación
1. Descargar IntelliJ IDEA Community (gratuita).
2. Instalar JDK (preferiblemente versión LTS como JDK 17).
3. Abrir IntelliJ y crear un nuevo proyecto Java/Kotlin.
4. Seleccionar el SDK del proyecto.
5. Configurar el sistema de build (Gradle o Maven si es necesario).

### Ventajas
* Autocompletado avanzado.
* Refactorización inteligente.
* Análisis profundo del código.
* Integración con herramientas empresariales.

IntelliJ es ideal para proyectos grandes y complejos.

## 2.3. Instalación de Eclipse
Eclipse es un IDE clásico, muy utilizado en entornos empresariales y en proyectos de gran tamaño. Aunque su interfaz 
es menos moderna, sigue siendo una herramienta robusta.

### Pasos de instalación
1. Descargar “Eclipse IDE for Java Developers”.
2. Descomprimir el paquete y ejecutar Eclipse.
3. Seleccionar un workspace (carpeta de trabajo).
4. Crear un proyecto Java o C++.
5. Añadir plugins si se necesitan funcionalidades adicionales.

### Ventajas
* Muy estable.
* Gran cantidad de plugins.
* Ideal para proyectos estructurados.

## 2.4. Instalación de NetBeans
NetBeans es un IDE sencillo y muy utilizado en formación. Su instalación es directa y no requiere configuraciones complejas.

### Pasos de instalación
1. Descargar el instalador desde la web oficial.
2. Instalar JDK si no está presente.
3. Ejecutar el instalador de NetBeans.
4. Crear un proyecto Java, PHP o C++.
5. Configurar librerías y dependencias.

### Ventajas
* Interfaz clara.
* Fácil de aprender.
* Ideal para estudiantes.

## 2.5. Consideraciones generales de instalación
Independientemente del IDE elegido, siempre es necesario:
* Instalar el lenguaje correspondiente (JDK, Python, .NET, GCC…).
* Verificar las rutas de compilación.
* Configurar el entorno para que el IDE detecte el compilador o intérprete.
* Comprobar que el proyecto se ejecuta correctamente tras la instalación.

Una instalación correcta garantiza que el IDE funcione sin errores y que el estudiante pueda centrarse en 
el desarrollo del software.
