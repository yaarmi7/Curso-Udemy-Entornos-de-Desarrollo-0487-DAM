# PARTE A — TEORÍA (4 puntos)

## EJERCICIO 1 (1,5 puntos)

a) Define qué es un IDE. **(0,4 puntos)**

Un IDE (*Integrated Development Environment*) es **una aplicación que integra en un solo entorno las herramientas
necesarias para desarrollar software**: edición de código, compilación, depuración, gestión de proyectos y otras
funciones de ayuda al programador.

b) Explica la diferencia entre un IDE y un editor de texto. **(0,4 puntos)**

Un editor de texto **solo permite escribir y guardar texto**, aunque pueda resaltar la sintaxis. Un IDE **añade
herramientas para compilar, depurar, autocompletar, refactorizar y gestionar el proyecto completo**, todo
integrado.

c) Indica cuatro componentes o herramientas que suele integrar un IDE. **(0,35 puntos)**

Cualquiera de estos (cuatro): editor de código con autocompletado, compilador o sistema de *build*, depurador,
gestor de proyectos, terminal integrada, integración con control de versiones (Git), gestor de extensiones, herramientas
de refactorización y análisis estático.

d) Explica la diferencia entre extensión y módulo, con un ejemplo de cada uno. **(0,35 puntos)**

Una **extensión** es un complemento que **añade funcionalidades al entorno** sin modificar el programa principal.
Ejemplo: *Java Extension Pack* o *Prettier* en VS Code. Un **módulo** es un **componente interno que amplía las
capacidades del IDE o del proyecto**. Ejemplo: soporte Maven o Gradle. En la práctica muchos IDEs usan indistintamente
los términos *plugin*, *módulo* o *extensión*.

## EJERCICIO 4 — Snippet y ajustes del editor (1,5 puntos)

a) **Snippet (0,75 puntos).** En `File` → `Preferences` → `Configure Snippets` → **Java**, archivo `java.json`:

```json
{
  "Bucle for con contador": {
    "prefix": "bucle",
    "body": [
      "for (int ${1:i} = 0; ${1:i} < ${2:n}; ${1:i}++) {",
      "\t$0",
      "}"
    ],
    "description": "Bucle for con contador"
  }
}
```

Al escribir `bucle` y pulsar `Tab` en `Prueba.java`, se inserta el bucle. `${1:i}` aparece tres veces: al cambiar
el nombre del contador se actualizan las tres posiciones a la vez. `${2:n}` es el segundo punto de edición y `$0`
la posición final del cursor, dentro del bloque.

**Criterios de corrección:** JSON válido con `prefix` y `body` (0,25) · contador editable en las tres posiciones con
`${1:i}` (0,25) · límite como segundo punto de edición y uso real del snippet con captura (0,25).

b) **Ajustes (0,75 puntos).** Contenido de `settings.json`:

```json
{
  "files.autoSave": "afterDelay",
  "editor.tabSize": 4,
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode"
}
```

**Criterios de corrección:** guardado automático (0,15) · 4 espacios por tabulación (0,15) · formato al guardar
(0,25) · formateador por defecto Prettier (0,20).

## EJERCICIO 5 — Linter y formateador (1,5 puntos)

a) **Avisos de Pylint (0,75 puntos).** Avisos esperados (al menos tres distintos):

| Línea | Código | Significado                                                        |
| ----- | ------ | ------------------------------------------------------------------ |
| 1     | C0114  | Falta la documentación del módulo (*missing-module-docstring*)     |
| 1     | W0611  | Importación sin usar: `sys` (*unused-import*)                      |
| 2     | W0611  | Importación sin usar: `os` (*unused-import*)                       |
| 4     | C0116  | Falta la documentación de la función (*missing-function-docstring*) |
| 6     | W0612  | Variable sin usar: `resultado` (*unused-variable*)                 |

La lista exacta puede variar según la versión de Pylint.

**Criterios de corrección:** Pylint activo y panel *Problems* mostrado (0,25) · tres avisos distintos con línea y
significado correctos (0,50).

b) **Código corregido y formateado (0,75 puntos).**

```python
"""Cálculo del área de un círculo."""


def area(radio):
    """Devuelve el área de un círculo del radio indicado."""
    pi = 3.14159
    resultado = pi * radio**2
    return resultado


print(area(2))
```

Cambios realizados: se eliminaron las dos importaciones sin usar, se corrigió el **error lógico** (la función
devolvía `pi` en vez de `resultado`), se añadieron las documentaciones y el formateador ajustó espacios, líneas en
blanco y la llamada a `print`.

Salida al ejecutar:

```
12.56636
```

**Criterios de corrección:** importaciones eliminadas y avisos resueltos (0,25) · error lógico corregido, resultado
`12.56636` (0,25) · formateo aplicado con un formateador (0,25).

## EJERCICIO 6 — Tarea automatizada (1,5 puntos)

`.vscode/tasks.json`:

```json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "Compilar",
      "type": "shell",
      "command": "gcc saludo.c -o saludo",
      "group": {
        "kind": "build",
        "isDefault": true
      },
      "problemMatcher": ["$gcc"]
    },
    {
      "label": "Ejecutar",
      "type": "shell",
      "command": "./saludo",
      "dependsOn": "Compilar",
      "problemMatcher": []
    }
  ]
}
```

En Windows, el comando de la segunda tarea sería `.\\saludo.exe` (con la barra invertida escapada en el JSON).

a) **Tarea Compilar (0,75 puntos).** Con `Ctrl + Shift + B` se ejecuta `gcc saludo.c -o saludo` y se genera el
ejecutable `saludo`.

**Criterios de corrección:** tarea con `label` y `command` correctos (0,25) · definida como *build* predeterminada con
`group` (0,25) · ejecutada con el atajo y ejecutable generado (0,25).

b) **Tarea Ejecutar (0,75 puntos).** Al lanzar `Terminal` → `Run Task` → **Ejecutar**, VS Code ejecuta primero
**Compilar** (por `dependsOn`) y después el programa. La salida mostrada es:

```
Examen Tema 2
```

**Criterios de corrección:** segunda tarea correcta (0,25) · dependencia con `dependsOn` (0,25) · ejecución desde
*Run Task* con la salida correcta (0,25).

## EJERCICIO 7 — Generación de un ejecutable Java (1,5 puntos)

a) **Comandos (0,75 puntos).**

```bash
javac Saludo.java                          # genera Saludo.class
jar cfe saludo.jar Saludo Saludo.class     # crea saludo.jar con Saludo como clase principal
```

**Criterios de corrección:** compilación con `javac` (0,25) · comando `jar cfe` correcto con clase principal
`Saludo` (0,50).

b) **Comprobación y ejecución (0,75 puntos).**

java -jar saludo.jar

**Criterios de corrección:** contenido mostrado con `jar tf` (0,25) · ejecución con `java -jar` y salida correcta
(0,25) · listado de archivos generados (0,25).
