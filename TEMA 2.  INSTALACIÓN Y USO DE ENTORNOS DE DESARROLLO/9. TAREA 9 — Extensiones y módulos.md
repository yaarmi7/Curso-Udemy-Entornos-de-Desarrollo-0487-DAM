# TAREA 9 — Extensiones y módulos

## Objetivo
Aprender a instalar, configurar y gestionar extensiones en un entorno de desarrollo real.

## Actividad práctica
Utilizando Visual Studio Code:
1. Instala las siguientes extensiones:
* Java Extension Pack
* GitLens
* Prettier
2. Realiza una captura (o describe) el proceso de instalación de cada una. ***(3.50 puntos)***
3. Explica para qué sirve cada extensión. ***(1.50 puntos)***
4. Comprueba que las tres aparecen como instaladas y activas. ***(1.25 puntos)***
5. Desactiva temporalmente una de las extensiones. ***(1.25 puntos)***
6. Vuelve a activarla. ***(1.25 puntos)***
7. Elabora una tabla con: ***(1.25 puntos)***
* Nombre de la extensión.
* Función principal.
* Estado (Instalada, Desactivada o Activa).
