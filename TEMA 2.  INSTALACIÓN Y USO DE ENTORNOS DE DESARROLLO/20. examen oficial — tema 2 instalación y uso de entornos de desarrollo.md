# PARTE B — PRÁCTICA CON ORDENADOR (6 puntos)

## EJERCICIO 4 — Snippet y ajustes del editor

**Total: 1,5 puntos**

a) Crea en VS Code un **snippet** para Java con el prefijo `bucle` que inserte un bucle `for` con contador:

```java
for (int i = 0; i < n; i++) {
    
}
```

El nombre del contador (`i`) debe poder cambiarse y actualizarse en las tres posiciones a la vez, y el límite (`n`)
debe ser un segundo punto de edición. Crea un archivo `Prueba.java`, utiliza el snippet y entrega el JSON del snippet
y una captura del resultado. **(0,75 puntos)**

b) Configura `settings.json` para que VS Code **guarde automáticamente** los archivos tras un breve tiempo, use
**4 espacios** por tabulación y **formatee al guardar** con Prettier. Entrega el contenido de `settings.json`.
**(0,75 puntos)**

## EJERCICIO 5 — Linter y formateador

**Total: 1,5 puntos**

Crea el archivo `area.py` con el siguiente código:

```python
import sys
import os

def area(radio):
    pi=3.14159
    resultado = pi*radio**2
    return pi
print( area(2) )
```

a) Con **Pylint** activo, abre el panel *Problems* y anota al menos **tres avisos** distintos indicando línea y
significado. Entrega una captura. **(0,75 puntos)**

b) Corrige el código para eliminar los avisos (incluido el error lógico), formatéalo con un **formateador** (Black o
el que tengas instalado) y entrega el código final junto con el resultado que muestra al ejecutarlo.
**(0,75 puntos)**

## EJERCICIO 6 — Tarea automatizada

**Total: 1,5 puntos**

Crea el archivo `saludo.c`:

```c
#include <stdio.h>

int main(void) {
    printf("Examen Tema 2\n");
    return 0;
}
```

a) Crea en `.vscode/tasks.json` una tarea llamada **Compilar**, definida como tarea de *build* predeterminada, que
compile `saludo.c` con `gcc` generando el ejecutable `saludo`. Ejecútala con `Ctrl + Shift + B`. **(0,75 puntos)**

b) Crea una segunda tarea llamada **Ejecutar** que lance el programa y que **dependa de la tarea Compilar**, de modo
que al ejecutarla se compile primero automáticamente. Lánzala desde `Terminal` → `Run Task` y entrega el
`tasks.json` completo y una captura de la salida. **(0,75 puntos)**

## EJERCICIO 7 — Generación de un ejecutable Java

**Total: 1,5 puntos**

Crea el archivo `Saludo.java`:

```java
public class Saludo {
    public static void main(String[] args) {
        System.out.println("Examen Tema 2");
    }
}
```

a) Desde la terminal, compílalo y genera un **JAR ejecutable** llamado `saludo.jar` cuya clase principal sea
`Saludo`. Entrega los comandos utilizados. **(0,75 puntos)**

b) Muestra el contenido del JAR con el comando adecuado, ejecútalo con `java -jar` y entrega la salida de ambos
comandos junto con el listado de los archivos generados. **(0,75 puntos)**
