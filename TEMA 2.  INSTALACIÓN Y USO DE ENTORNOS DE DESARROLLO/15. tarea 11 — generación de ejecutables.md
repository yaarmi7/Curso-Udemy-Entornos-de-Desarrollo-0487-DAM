# TAREA 11 — Generación de ejecutables

**Distribución de la puntuación**: Práctica con el ordenador **7 puntos (70%)** · Teoría **3 puntos (30%)**

**Material necesario**: JDK (con `javac` y `jar`), `gcc`, Python con `pip` y uno de estos IDEs: IntelliJ IDEA,
Eclipse o NetBeans.

**Entrega**: un documento con tus respuestas, capturas de la terminal de cada paso, el listado de archivos generados
y el código fuente utilizado.

## PARTE PRÁCTICA (7 puntos)

1. **Java desde la terminal.** Crea `Main.java` con un programa que muestre `Hola Mundo`. Compílalo con `javac`,
   ejecútalo con `java`, genera un **JAR ejecutable** con el comando `jar` y ejecútalo con `java -jar`. Muestra el
   contenido del JAR con `jar tf`. Entrega los comandos, la salida de cada uno y el listado de archivos.
   ***(2.00 puntos)***

2. **C con dos archivos fuente.** Crea tres archivos: `util.h` y `util.c` (con una función `int sumar(int a, int b)`)
   y `main.c` (que la utilice y muestre el resultado de `sumar(2, 3)`). Genera por separado los dos archivos objeto
   con `gcc -c`, enlázalos para crear el ejecutable y ejecútalo. Después intenta enlazar **solo** `main.o` y anota el
   error que aparece. Entrega los comandos, las salidas y el listado de archivos. ***(2.00 puntos)***

3. **Python con PyInstaller.** Crea un script `saludo.py` que pida un nombre y lo salude. Ejecútalo con `python` y
   genera después un ejecutable de un solo archivo con PyInstaller. Indica en qué carpeta aparece, qué otras carpetas
   y archivos se crean y ejecuta el programa generado. ***(1.50 puntos)***

4. **El mismo código en un IDE.** Importa o crea el mismo programa Java del apartado 1 en **un IDE** (IntelliJ,
   Eclipse o NetBeans) y genera el JAR ejecutable desde el propio IDE. Ejecútalo con `java -jar` y compara su
   contenido (`jar tf`) con el JAR creado desde la terminal. Entrega los pasos seguidos, la ruta del JAR generado y
   la comparación. ***(1.50 puntos)***

## PARTE TEÓRICA (3 puntos)

5. Explica la diferencia entre compilar en modo **Debug** y en modo **Release** y completa una tabla con los tres
   lenguajes trabajados (Java, C y Python) indicando tipo de lenguaje, archivos generados y herramienta utilizada.
   ***(1.50 puntos)***

6. Explica qué es el **código objeto**, por qué `main.o` no se puede ejecutar y qué papel cumple el **enlazador**.
   Explica además la diferencia entre un ejecutable nativo y un JAR (bytecode). ***(1.50 puntos)***
