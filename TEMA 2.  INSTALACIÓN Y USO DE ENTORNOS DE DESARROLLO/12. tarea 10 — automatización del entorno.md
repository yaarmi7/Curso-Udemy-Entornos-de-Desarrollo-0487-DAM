# TAREA 10 — Automatización del entorno

**Distribución de la puntuación**: Práctica con el ordenador **7 puntos (70%)** · Teoría **3 puntos (30%)**

**Material necesario**: Visual Studio Code, compilador `gcc` y Python instalados.

**Entrega**: un documento con tus respuestas, capturas de pantalla de cada paso y los archivos de configuración
creados (`snippet`, `tasks.json`, `settings.json` y el código utilizado).

## PARTE PRÁCTICA (7 puntos)

1. **Snippet propio.** En VS Code crea un snippet para Java con el prefijo `sout` que inserte
   `System.out.println("");` dejando el cursor entre las comillas. Crea un archivo `Prueba.java`, utiliza el snippet
   y comprueba que funciona. Entrega el JSON del snippet y una captura del resultado. ***(1.50 puntos)***

2. **Tarea de compilación.** Crea un archivo `main.c` con un programa "Hola Mundo". Configura en `.vscode/tasks.json`
   una tarea de *build* predeterminada que lo compile con `gcc`. Ejecútala con `Ctrl + Shift + B` y ejecuta después
   el programa obtenido. Entrega el `tasks.json`, una captura de la terminal y el nombre del archivo generado.
   ***(2.00 puntos)***

3. **Linter.** Instala la extensión **Pylint** (junto con la extensión de Python). Crea el archivo `prueba.py` con
   este código:

   ```python
   import os

   def calcular(a, b):
       resultado = a + b
       return a
   ```

   Abre el panel *Problems* y anota todos los avisos que aparezcan. Después corrige el código hasta eliminar los
   avisos y entrega una captura del antes y del después con el código corregido. ***(1.50 puntos)***

4. **Formateador y formato al guardar.** Instala **Prettier - Code Formatter**. Crea un archivo `desordenado.js`
   con este código:

   ```javascript
   const suma = (a,b) =>{return a+b}
   console.log( suma(2,3) )
   ```

   Configura `settings.json` para que VS Code formatee el archivo **al guardar** usando Prettier. Guarda el archivo
   y entrega el código antes y después, junto con el contenido de `settings.json`. ***(2.00 puntos)***

6. Explica cómo comprobarías si hay actualizaciones de tu IDE y por qué es recomendable mantenerlo actualizado.
