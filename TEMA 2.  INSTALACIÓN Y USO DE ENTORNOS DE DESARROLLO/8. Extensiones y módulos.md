# 3. Extensiones y módulos

Uno de los aspectos que ha convertido a los IDEs modernos en herramientas tan potentes es su capacidad para ampliarse 
mediante extensiones, plugins o módulos. Gracias a estos componentes adicionales, un IDE puede adaptarse a prácticamente 
cualquier lenguaje de programación, framework o necesidad específica de un proyecto.

Cuando instalamos un IDE por primera vez, normalmente solo disponemos de las funciones básicas. Sin embargo, mediante 
extensiones podemos incorporar nuevas herramientas que mejoran la edición de código, la depuración, la gestión de bases de 
datos, el análisis de calidad, la integración con Git y muchas otras funcionalidades.

Por este motivo, conocer cómo instalar, configurar y administrar extensiones es una competencia fundamental para cualquier 
desarrollador.

## 3.1. ¿Qué son las extensiones?

Una extensión es un complemento que añade nuevas funcionalidades a un entorno de desarrollo sin modificar el programa 
principal.

Su objetivo es permitir que cada desarrollador personalice su entorno según:

- El lenguaje que utiliza.
- El tipo de proyecto.
- Sus preferencias de trabajo.
- Las necesidades del equipo de desarrollo.

Por ejemplo, un desarrollador Java necesitará herramientas diferentes a las de un desarrollador web o de un programador de 
Python.

## 3.2. ¿Qué son los módulos?

Aunque a menudo se utilizan como sinónimos, no siempre significan lo mismo.

### Extensión
Añade funcionalidades al entorno.

**Ejemplos:**
- Java Extension Pack.
- Python Extension.
- ESLint.
- Prettier.

### Módulo
Componente interno que amplía las capacidades del IDE o del proyecto.

**Ejemplos:**
- Soporte Maven.
- Soporte Gradle.
- Herramientas UML.
- Módulos de Spring Boot.

En la práctica, muchos IDEs utilizan indistintamente los términos *plugin*, *módulo* o *extensión*.

## 3.3. Instalación de extensiones

Cada IDE dispone de un gestor específico.

### En Visual Studio Code
1. Abrir el panel de extensiones.
2. Buscar la extensión deseada.
3. Pulsar **Install**.
4. Reiniciar el IDE si es necesario.

**Ejemplos habituales:**

| Extensión | Utilidad |
| :--- | :--- |
| **Java Extension Pack** | Desarrollo Java |
| **Python** | Desarrollo Python |
| **C/C++** | Desarrollo C y C++ |
| **GitLens** | Integración avanzada con Git |
| **Live Server** | Desarrollo web |

### En IntelliJ IDEA
1. Menú `File` → `Settings`.
2. Seleccionar `Plugins`.
3. Buscar la extensión.
4. Instalar.
5. Reiniciar IntelliJ.

### En Eclipse
1. `Help` → `Eclipse Marketplace`.
2. Buscar el complemento.
3. Instalar.
4. Reiniciar Eclipse.

### En NetBeans
1. `Tools` → `Plugins`.
2. Buscar complemento.
3. Instalar.
4. Reiniciar NetBeans.

## 3.4. Configuración de extensiones

Instalar una extensión suele ser solo el primer paso. Muchas requieren configuración adicional:

### Ejemplo: Python en VS Code
Es necesario indicar:
- Versión de Python.
- Ruta del intérprete.
- Entorno virtual.

### Ejemplo: Java Extension Pack
Requiere:
- JDK instalado.
- Configuración de `JAVA_HOME`.
- Detección automática del SDK.

Una mala configuración puede provocar errores aunque la extensión esté correctamente instalada.

## 3.5. Actualización de extensiones

Las extensiones se actualizan periódicamente para:
- Corregir errores.
- Añadir funciones nuevas.
- Mejorar compatibilidad.
- Solucionar problemas de seguridad.

Por ello es recomendable mantenerlas actualizadas. La mayoría de IDEs ofrecen actualización automática.

## 3.6. Desinstalación y desactivación

No todas las extensiones son necesarias permanentemente. Un exceso de complementos puede:
- Aumentar el consumo de memoria.
- Hacer más lento el IDE.
- Generar conflictos.

Por ello es importante:
- Desinstalar extensiones que no se utilicen.
- Desactivar temporalmente aquellas que interfieran con otras.

## 3.7. Buenas prácticas al trabajar con extensiones

Al configurar un IDE profesional se recomienda:
* Instalar únicamente las extensiones necesarias.
* Mantenerlas actualizadas.
* Revisar permisos y seguridad.
* Evitar extensiones redundantes.
* Documentar las utilizadas en el proyecto.

De esta forma se consigue un entorno estable y fácil de mantener.
