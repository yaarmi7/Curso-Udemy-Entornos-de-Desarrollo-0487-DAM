# TAREA 12 — Comparativa de IDEs

**Distribución de la puntuación**: Práctica con el ordenador **7 puntos (70%)** · Teoría **3 puntos (30%)**

**Material necesario**: Visual Studio Code y un segundo IDE a tu elección (IntelliJ IDEA, Eclipse o NetBeans),
con un JDK instalado.

**Entrega**: un documento con tus respuestas, capturas de pantalla de cada prueba, las tablas de resultados
completadas y el código utilizado.

## PARTE PRÁCTICA (7 puntos)

Vas a comparar **dos IDEs reales** probándolos en tu propio equipo con **el mismo proyecto**.

1. **Mismo proyecto en dos IDEs.** Crea en ambos IDEs un proyecto Java con una clase `Calculadora` que tenga un método
   `sumar(int a, int b)` y un `main` que muestre el resultado de `sumar(4, 5)`. Compílalo y ejecútalo en los dos.
   Entrega el código y una captura de la ejecución en cada IDE. ***(1.50 puntos)***

2. **Medición de recursos y arranque.** Con cada IDE:
   - Cronometra el tiempo que tarda en abrirse y mostrar el proyecto (en segundos).
   - Con el proyecto abierto, anota la memoria RAM que consume el IDE usando el Administrador de tareas (Windows),
     el Monitor de actividad (macOS) o el comando `top` / `htop` (Linux).

   Entrega una tabla con los resultados de ambos IDEs y una captura del monitor de recursos. ***(2.00 puntos)***

3. **Prueba de tres funciones.** En ambos IDEs realiza estas tres pruebas y anota cómo se hace y si el resultado es
   satisfactorio:
   - **Autocompletado:** escribe `System.out.pr` y comprueba qué sugiere el IDE.
   - **Refactorización:** renombra el método `sumar` a `suma` de forma que se actualicen todas sus llamadas.
   - **Depuración:** coloca un *breakpoint* en la línea del `return` de `sumar`, ejecuta en modo depuración y
     observa los valores de `a` y `b`.

   Entrega una tabla comparativa y una captura de la depuración en cada IDE. ***(2.00 puntos)***

4. **Extensión o plugin equivalente.** Instala en ambos IDEs una extensión o plugin que cumpla una función similar
   (por ejemplo, soporte para Git, un tema de color o un formateador). Anota los pasos exactos en cada IDE y el
   número de pasos necesarios. ***(1.50 puntos)***

## PARTE TEÓRICA (3 puntos)

5. Elabora una tabla comparativa de **Visual Studio Code, IntelliJ IDEA, Eclipse y NetBeans** con al menos estos
   criterios: coste, lenguaje principal, consumo de recursos, facilidad de aprendizaje y extensibilidad.
   ***(1.50 puntos)***

6. Basándote en **tus propios resultados** del apartado práctico y en la teoría, elige el IDE más adecuado para
   estos dos proyectos y justifica tu decisión: ***(1.50 puntos)***
   - a) Una página web con HTML, CSS y JavaScript. ***(0.75 puntos)***
   - b) Una aplicación empresarial grande en Java con Spring y Maven. ***(0.75 puntos)***
