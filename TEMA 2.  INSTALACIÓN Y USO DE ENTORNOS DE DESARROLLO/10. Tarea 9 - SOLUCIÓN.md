# Tarea 9 - SOLUCIÓN

## 1. Instalación de las extensiones

### Extensión 1: Java Extension Pack
Proceso realizado:
1. Abrí Visual Studio Code.
2. Seleccioné el icono Extensions de la barra lateral izquierda.
3. Escribí Java Extension Pack en el cuadro de búsqueda.
4. Seleccioné la extensión de Microsoft.
5. Pulsé el botón Install.

**Resultado**: Extensión instalada correctamente.

### Extensión 2: GitLens
Proceso realizado:
1. Accedí al panel de extensiones.
2. Busqué GitLens.
3. Seleccioné la extensión oficial.
4. Pulsé Install.

**Resultado**: Instalación completada correctamente.

### Extensión 3: Prettier
Proceso realizado:
1. Abrí el panel de extensiones.
2. Busqué Prettier - Code Formatter.
3. Seleccioné la extensión.
4. Pulsé Install.

**Resultado**: Extensión instalada y lista para usar.

## 3. Función de cada extensión

### Java Extension Pack
Permite desarrollar aplicaciones Java en VS Code. Incluye herramientas para:
* Compilación.
* Depuración.
* Autocompletado.
* Gestión de proyectos Java.

### GitLens
Amplía las funcionalidades de Git dentro de VS Code.

Permite:
* Ver autoría de líneas de código.
* Consultar historial de cambios.
* Comparar versiones.
* Gestionar repositorios Git.

### Prettier
Es un formateador automático de código.

Permite:
* Corregir la indentación.
* Unificar estilos de programación.
* Mejorar la legibilidad del código.
* Aplicar formato automáticamente al guardar.

## 4. Comprobación de instalación

Después de la instalación accedí nuevamente al panel Extensions y comprobé que las tres extensiones aparecían con 
el estado:

**Installed**

Además, VS Code mostraba las extensiones como activas.

## 5. Desactivación temporal de una extensión
Se seleccionó la extensión GitLens.

Pasos realizados:
1. Abrí el panel de extensiones.
2. Seleccioné GitLens.
3. Pulsé la opción Disable.

Estado tras la acción:

**Desactivada**

## 6. Reactivación de la extensión
Para volver a activarla:
1. Seleccioné nuevamente GitLens.
2. Pulsé Enable.

Estado tras la acción:

**Activa**
