# TAREA 8 — SOLUCIÓN 

## PARTE 1 — INFORME DE DOS IDEs 

### IDE 1: Visual Studio Code

#### 1. Proceso de instalación paso a paso
1. Accedí a la web oficial: https://code.visualstudio.com
2. Descargué el instalador para Windows 64-bit.
3. Ejecuté VSCodeSetup.exe.
4. Acepté los términos de licencia.
5. Seleccioné instalación estándar.
6. Activé las opciones recomendadas:

a. Añadir VS Code al PATH

b. Crear acceso directo

7. Finalicé la instalación y abrí el programa.

#### 2. Requisitos adicionales
* Para Java → instalar JDK (preferiblemente JDK 17).
* Para Python → instalar Python desde python.org.
* Para C/C++ → instalar compiladores (GCC, Clang o MSVC).

#### 3. Cómo se crea un proyecto en VS Code
1. Abrí VS Code.
2. Seleccioné Open Folder y creé una carpeta llamada ProyectoVSCode.
3. Añadí un archivo Main.java o main.py.
4. VS Code detectó el lenguaje y activó autocompletado.
5. Ejecuté el archivo desde el botón Run.

#### 4. Comparación breve
VS Code es ligero, rápido y muy flexible.

Se adapta a cualquier lenguaje gracias a sus extensiones.

Ideal para proyectos web, Python, C#, C++ y Java.


### IDE 2: IntelliJ IDEA

#### 1. Proceso de instalación paso a paso
1. Accedí a https://www.jetbrains.com/idea
2. Descargué IntelliJ IDEA Community.
3. Instalé el programa con configuración estándar.
4. Instalé JDK 17.
5. Abrí IntelliJ y seleccioné New Project.
6. Elegí Java y asigné el SDK.
7. IntelliJ generó la estructura del proyecto automáticamente.

#### 2. Requisitos adicionales
* JDK obligatorio (versión 17 recomendada).
* Para Kotlin → no requiere instalación adicional.
* Para Maven/Gradle → se configuran desde el propio IDE.

#### 3. Cómo se crea un proyecto en IntelliJ
1. Abrí IntelliJ.
2. Seleccioné New Project.
3. Elegí Java y el SDK.
4. IntelliJ creó carpetas como src, main, resources.
5. Añadí una clase Java y ejecuté con el botón Run.

#### 4. Comparación breve

IntelliJ es más potente y completo que VS Code, especialmente para Java y Kotlin.

Su autocompletado, refactorización y análisis son superiores.

Es más pesado, pero ideal para proyectos grandes.

### Conclusión comparativa
* VS Code → más cómodo para empezar, más rápido, más flexible.
* IntelliJ → más profesional para Java/Kotlin, más herramientas avanzadas.

Personalmente, VS Code es más cómodo por su rapidez y simplicidad, pero IntelliJ es mejor para proyectos serios en Java.

## PARTE 2 — INSTALACIÓN PRÁCTICA DE VISUAL STUDIO CODE 

### 1. Descarga del instalador

Entré en la web oficial:

https://code.visualstudio.com

Descargué el instalador para Windows:

VSCodeSetup-x64.exe

### 2. Instalación completa del programa
1. Ejecuté el instalador.
2. Acepté los términos de licencia.
3. Seleccioné instalación estándar.
4. Activé:
   
a. Add to PATH

b. Create Desktop Icon

5. Finalicé la instalación.

### 3. Primera ejecución del IDE
Abrí VS Code desde el acceso directo.
* Apareció la pantalla de bienvenida con:
* Panel de archivos vacío
* Botón “Open Folder”
* Panel de extensiones
* Terminal integrada

Todo funcionó correctamente.

### 4. Instalación de una extensión obligatoria
Instalé Java Extension Pack:
1. Abrí el panel de extensiones.
2. Busqué “Java Extension Pack”.
3. Pulsé Install.
4. VS Code instaló automáticamente:

a. Language Support for Java

b. Debugger for Java

c. Maven

d. Test Runner

Extensión instalada correctamente.

### 5. Creación de un proyecto mínimo
1. Creé una carpeta llamada ProyectoVSCode.
2. Abrí la carpeta desde VS Code.
3. Añadí un archivo Main.java.
4. Escribí el siguiente código:
   ```java
public class Main {
  public static void main (String[] args) {
    System.out.println("VS Code funcionando correctamente");
  }
}
``
5. Guardé el archivo.

### 6. Comprobación del funcionamiento
Ejecuté el programa desde el botón Run.

Salida en la terminal:

*VS Code funcionando correctamente*

Esto confirma que:
* VS Code está instalado correctamente.
* La extensión de Java funciona.
* El compilador está configurado.
* El entorno es totalmente operativo.
