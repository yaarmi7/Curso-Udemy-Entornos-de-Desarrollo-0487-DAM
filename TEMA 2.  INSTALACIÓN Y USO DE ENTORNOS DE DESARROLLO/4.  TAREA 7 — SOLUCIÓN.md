# TAREA 7 — SOLUCIÓN

## 1. Definición clara de entorno de desarrollo
Un entorno de desarrollo es una herramienta software que reúne en un mismo lugar todo lo necesario para crear programas: 
edición de código, depuración, ejecución, análisis y gestión del proyecto. Es el espacio de trabajo del programador, 
donde se escribe, prueba y mantiene el software de forma organizada y eficiente.

## 2. Tres funciones principales esenciales
* Edición avanzada de código: con autocompletado, resaltado de sintaxis y detección de errores en tiempo real.
* Compilación y ejecución del programa: el IDE automatiza el proceso de construir y ejecutar el software
  sin necesidad de comandos manuales.
* Depuración: permite analizar el programa paso a paso, revisar variables y colocar breakpoints para encontrar errores.

## 3. Dos ventajas concretas de usar un IDE
* Mayor productividad: el programador trabaja más rápido gracias a herramientas inteligentes que reducen
  errores y automatizantareas.
* Mejor organización del proyecto: el IDE gestiona archivos, dependencias y configuraciones, evitando problemas
  de estructura y facilitando el mantenimiento.

## 4. Ejemplo real de un IDE y tipo de proyectos donde se utiliza
Visual Studio Code (VS Code) es un IDE ligero y modular que se utiliza en proyectos de desarrollo web (HTML, CSS, JavaScript), 
aplicaciones en Python, C#, C++ y entornos de trabajo modernos basados en frameworks como React, Angular o Node.js.
